# CRM – מערכת ניהול לקוחות לעסק שיווק דיגיטלי

פרויקט בבנייה, שלב אחרי שלב.

**מה קיים כרגע:**
1. מסך התחברות (Login)
2. דשבורד ראשי (Dashboard) – סרגל צד כהה + אזור תוכן בהיר

---

## איך מריצים את המערכת אצלי במחשב?

### פעם אחת בלבד – התקנה

1. ודא שמותקן אצלך **Node.js** (גרסה 18 ומעלה).
   אם לא – הורד מ-https://nodejs.org ולחץ Next עד הסוף.
2. פתח **טרמינל** (ב-Mac: אפליקציית Terminal. ב-Windows: PowerShell)
   בתוך תיקיית הפרויקט.
3. הרץ את הפקודה הבאה והמתן שתסתיים:

```bash
npm install
```

### בכל פעם שרוצים לראות את המערכת

```bash
npm run dev
```

הדפדפן ייפתח אוטומטית בכתובת **http://localhost:3000**.
כדי לעצור את השרת: לחץ `Ctrl + C` בטרמינל.

> טיפ: כל שינוי בקוד מתעדכן במסך מיד, בלי לרענן.

| שדה   | ערך              |
| ----- | ---------------- |
| אימייל | `admin@crm.co.il` |
| סיסמה | `123456`          |

הפרטים האלה מוגדרים כרגע בקוד לצורכי הדגמה בלבד
(`src/pages/Login.jsx`, המשתנה `DEMO_USER`).
בשלב מאוחר יותר נחליף אותם בהתחברות אמיתית מול שרת ומסד נתונים.

## מה יש בתיקייה?

```
index.html            – קובץ הבסיס שהדפדפן טוען
package.json          – רשימת הכלים והפקודות של הפרויקט
vite.config.js        – הגדרות שרת הפיתוח (הפורט וכו')
src/
  main.jsx            – נקודת הכניסה שמפעילה את האפליקציה
  App.jsx             – מחליט איזה מסך להציג (התחברות / דשבורד)
  styles.css          – מחבר יחד את קבצי העיצוב
  styles/
    tokens.css        – ** כל הצבעים והפינות של המערכת – במקום אחד **
    login.css         – עיצוב מסך ההתחברות
    dashboard.css     – עיצוב הדשבורד
  data/
    mockData.js       – ** כל נתוני הדמו – במקום אחד **
  pages/
    Login.jsx         – מסך ההתחברות
    Dashboard.jsx     – מסך הדשבורד (מרכיב את כל החלקים יחד)
  components/
    Sidebar.jsx       – סרגל הצד הכהה עם התפריט
    Topbar.jsx        – הסרגל העליון: ברכה, חיפוש, התראות
    StatCard.jsx      – כרטיס מדד עם מספר גדול וגרף מגמה קטן
    LeadsChart.jsx    – גרף העמודות המרכזי
    SourcesChart.jsx  – פילוח מקורות הלידים
    RecentLeads.jsx   – טבלת הלידים האחרונים
    TasksCard.jsx     – רשימת המשימות של היום
    icons.jsx         – כל האייקונים של המערכת
```

### שני קבצים ששווה להכיר

- **`src/styles/tokens.css`** – כל צבע במערכת מוגדר שם פעם אחת.
  שינוי של שורה אחת שם משנה את הצבע בכל המסכים.
- **`src/data/mockData.js`** – כל המספרים שמופיעים בדשבורד.
  אפשר לשנות אותם ולראות מיד את התוצאה על המסך.

## מה כבר עובד

### מסך ההתחברות
- בדיקת תקינות אימייל וסיסמה עם הודעות שגיאה בעברית
- הצגה/הסתרה של הסיסמה
- "זכור אותי" ו"שכחתי סיסמה"
- מצב טעינה בכפתור בזמן ההתחברות
- הודעת שגיאה כאשר הפרטים שגויים

### הדשבורד
- **סרגל צד כהה** עם 7 פריטי תפריט, סימון המסך הפעיל ומוני התראות
- **ארבעה כרטיסי מדד** – לידים, עסקאות, הכנסות ושיעור המרה,
  כל אחד עם גרף מגמה קטן והשוואה לחודש הקודם
- **גרף עמודות** של לידים מול עסקאות לפי חודש, עם חלונית מידע במעבר עכבר
  וכפתור מעבר לתצוגת טבלה
- **פילוח מקורות הלידים** בעמודות אופקיות
- **טבלת הלידים האחרונים** עם תגיות סטטוס צבעוניות
- **רשימת משימות** עם סימון וי ומד התקדמות
- התאמה מלאה למסכי טאבלט ומובייל (התפריט הופך למגירה נפתחת)

### על צבעי הגרפים
זוג הצבעים בגרפים (סגול וירוק-טורקיז) נבחר ונבדק אוטומטית כך שיהיה
ניתן להבחין ביניהם גם עבור אנשים עם עיוורון צבעים, ושהניגודיות מול
הרקע הלבן תעמוד בתקן הנגישות. בנוסף, כל סטטוס וכל סדרה בגרף מלווים
תמיד בטקסט – הצבע לעולם אינו המידע היחיד.
