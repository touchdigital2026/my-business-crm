# CRM – מערכת ניהול לקוחות לעסק שיווק דיגיטלי

פרויקט בבנייה, שלב אחרי שלב.

**מה קיים כרגע:**
1. מסך התחברות (Login)
2. דשבורד ראשי (Dashboard) – שבעת הנתונים שמוגדרים בסעיף 13 באפיון
3. מסך ניהול לידים (Leads) – רשימה, חיפוש, סינון והמרת ליד ללקוח (סעיף 4)

---

## איך מריצים את המערכת אצלי במחשב?

### פעם אחת בלבד – התקנה

1. ודא שמותקן אצלך **Node.js** (גרסה 18 ומעלה).
   אם לא – הורד מ-https://nodejs.org ולחץ Next עד הסוף.
2. פתח **טרמינל** (ב-Mac: אפליקציית Terminal. ב-Windows: PowerShell)
   בתוך תיקיית הפרויקט.
3. הרץ את הפקודה הבאה והמתן שתסתיים:

```bash
npm install
```

### בכל פעם שרוצים לראות את המערכת

```bash
npm run dev
```

הדפדפן ייפתח אוטומטית בכתובת **http://localhost:3000**.
כדי לעצור את השרת: לחץ `Ctrl + C` בטרמינל.

> טיפ: כל שינוי בקוד מתעדכן במסך מיד, בלי לרענן.

### איך המערכת מחוברת לעצמה

`src/store/CrmContext.jsx` מחזיק את שלוש הרשימות המרכזיות – לידים,
לקוחות ומשימות – במקום אחד. כל המסכים קוראים משם, ולכן פעולה במסך אחד
מתעדכנת מיד בכל השאר: המרת ליד ללקוח מעלה את מוני התפריט, מוסיפה לקוח
לכרטיס החבילות, ומוסיפה את משימות ההקמה לכרטיס המשימות שבדשבורד.

### שני קבצים ששווה להכיר

- **`src/styles/tokens.css`** – כל צבע במערכת מוגדר שם פעם אחת.
  שינוי של שורה אחת שם משנה את הצבע בכל המסכים.
- **`src/data/mockData.js`** – כל המספרים שמופיעים בדשבורד.
  אפשר לשנות אותם ולראות מיד את התוצאה על המסך.

## מה כבר עובד

### מסך ההתחברות
- בדיקת תקינות אימייל וסיסמה עם הודעות שגיאה בעברית
- הצגה/הסתרה של הסיסמה, "זכור אותי", מצב טעינה והודעת שגיאה

### הדשבורד – לפי סעיף 13 באפיון
| # | דרישה באפיון | איפה זה מופיע |
| - | ------------ | ------------- |
| 13.1 | מספר לקוחות פעילים, לפי חבילה | כרטיס "לקוחות פעילים לפי חבילה" + כרטיס מדד |
| 13.2 | הכנסה חודשית ותחזית הכנסה מחבילות בהקמה | כרטיס מדד "הכנסה חודשית" + מסך רווח והפסד |
| 13.3 | הוצאות חודשיות ומסך רווח/הפסד | גרף "הכנסות מול הוצאות" + שורת הרווח |
| 13.4 | משימות פתוחות ובאיחור, סה"כ ולפי אחראי | כרטיס "משימות" |
| 13.5 | פייפליין מכירות – לידים בכל שלב ואחוז המרה | כרטיס "פייפליין מכירות" |
| 13.6 | לקוחות בסיכון תשלום | טבלת "לקוחות בסיכון תשלום" |
| 13.7 | ביצועי קבלני משנה – זמן ממוצע למשימה | כרטיס "ביצועי קבלני משנה" |

### מסך ניהול הלידים – לפי סעיף 4 באפיון
- **רשימה מלאה** עם כל פרטי הליד מסעיף 4.2: מקור, איש מכירות אחראי,
  חבילה מוצעת, שווי פוטנציאלי, תאריך פנייה אחרונה ותזכורת למעקב הבא
- **חיפוש חופשי** לפי שם, עסק, טלפון או אימייל
- **סינון** לפי שלב בפייפליין (5 השלבים מסעיף 4.1), לפי מקור הליד
  (הפניה / פה לאוזן / שיווק נכנס / אחר) ולפי סטטוס
- **המרת ליד ללקוח בלחיצה אחת** (סעיף 4.3): נפתח חלון שמראה מראש
  בדיוק אילו משימות הקמה ייווצרו ומה יעד הזמן של כל אחת; באישור –
  הליד מסומן כנסגר, נפתח כרטיס לקוח בשלב "הקמה", ונוצרות אוטומטית
  משימות ההקמה של החבילה עם תאריך יעד מחושב

| חבילה | משימות הקמה שנפתחות |
| ----- | ------------------- |
| סטנדרט | 4 |
| ביניים | 9 |
| פרימיום | 11 |

יעדי הזמן מגיעים מטבלת ה-SLA בסעיף 6.2. ארבע משימות מסומנות בתגית
**"לאישור"** – אלה משימות שאין להן שורה מפורשת בטבלה, ולכן יעד הזמן
שלהן הוא הצעה שממתינה לאישורך: הקמת ביו שיווקי, הקמת CRM ללקוח,
הקמת מספר וירטואלי, והקמת שיווק אורגני בגוגל ו-AI.

### התאמה לסעיף 16 (Design System)
- סרגל צד בגוון נייבי-סגלגל עמוק (`#1B1830`→`#16131F`), פריט פעיל ברקע סגול מלא
- אקצנט סגול עם גרדיאנט `#7C5CFC`→`#5B3DF5`, רקע תוכן `#F7F7FB`, כרטיסים לבנים בצל רך
- פינות: כרטיסים 22px, כפתורים 14px/Pill, שדות 12px, תגיות מעוגלות לחלוטין
- גופן Assistant, עשרת מודולי התפריט מסעיף 16.3, חיפוש גלובלי בסרגל הצד,
  נתיב ניווט ומחוון מכסת אחסון בסרגל העליון, וכרטיס התראה קבוע בתחתית הסרגל
- Breakpoints לפי 16.6: דסקטופ 1200px+, טאבלט 768–1199px, מובייל עד 767px

### על צבעי הגרפים
הזוג סגול/כתום שבגרף הפיננסי נבדק אוטומטית ועובר את כל תקני הנגישות על רקע
לבן, כולל הבחנה עבור עיוורון צבעים. שלוש דרגות החבילות צבועות בסולם סגול
מדורג (בהיר→כהה) שמשקף את סדר הדרגות. כל תגית סטטוס מוצגת תמיד עם טקסט –
הצבע לעולם אינו המידע היחיד.

## השלב הבא

מסך ניהול הלקוחות (סעיף 3): כרטיס לקוח מלא עם הנכסים הדיגיטליים,
יומן תקשורת, משימות והיסטוריית תשלומים — כולל הלקוחות שנוצרו
מהמרת לידים.
