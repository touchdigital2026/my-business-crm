# CRM – מערכת ניהול לקוחות לעסק שיווק דיגיטלי

פרויקט בבנייה, שלב אחרי שלב. כרגע קיים **מסך ההתחברות (Login)**.

---

## איך מריצים את המערכת אצלי במחשב?

### פעם אחת בלבד – התקנה

1. ודא שמותקן אצלך **Node.js** (גרסה 18 ומעלה).
   אם לא – הורד מ-https://nodejs.org ולחץ Next עד הסוף.
2. פתח **טרמינל** (ב-Mac: אפליקציית Terminal. ב-Windows: PowerShell)
   בתוך תיקיית הפרויקט.
3. הרץ את הפקודה הבאה והמתן שתסתיים:

```bash
npm install
```

### בכל פעם שרוצים לראות את המערכת

```bash
npm run dev
```

הדפדפן ייפתח אוטומטית בכתובת **http://localhost:3000**.
כדי לעצור את השרת: לחץ `Ctrl + C` בטרמינל.

> טיפ: כל שינוי בקוד מתעדכן במסך מיד, בלי לרענן.

## פרטי כניסה לבדיקה (זמניים)

| שדה   | ערך              |
| ----- | ---------------- |
| אימייל | `admin@crm.co.il` |
| סיסמה | `123456`          |

הפרטים האלה מוגדרים כרגע בקוד לצורכי הדגמה בלבד
(`src/pages/Login.jsx`, המשתנה `DEMO_USER`).
בשלב מאוחר יותר נחליף אותם בהתחברות אמיתית מול שרת ומסד נתונים.

---

## מה יש בתיקייה?

```
index.html          – קובץ הבסיס שהדפדפן טוען
package.json        – רשימת הכלים והפקודות של הפרויקט
vite.config.js      – הגדרות שרת הפיתוח (הפורט וכו')
src/
  main.jsx          – נקודת הכניסה שמפעילה את האפליקציה
  App.jsx           – מחליט איזה מסך להציג (התחברות / מחובר)
  styles.css        – כל העיצוב: צבעים, כפתורים, שדות
  pages/
    Login.jsx       – מסך ההתחברות עצמו
```

## ערכת העיצוב

## מה כבר עובד במסך ההתחברות

- בדיקת תקינות אימייל וסיסמה עם הודעות שגיאה בעברית
- הצגה/הסתרה של הסיסמה
- "זכור אותי" ו"שכחתי סיסמה"
- מצב טעינה בכפתור בזמן ההתחברות
- הודעת שגיאה כאשר הפרטים שגויים
- מסך אישור זמני אחרי התחברות מוצלחת
